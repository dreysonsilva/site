## 💻 Sobre
Esta página foi desenvolvida com o objetivo de ser uma Central de Recursos e Suporte (Help Hub). A ideia nasceu da necessidade de organizar e facilitar o acesso a documentos, guias e links essenciais que muitas vezes ficam dispersos em diferentes plataformas.
O projeto atua em duas frentes principais:

Colaboração Interna: Agiliza o fluxo de trabalho da equipe, centralizando manuais técnicos, modelos de arquivos e acessos rápidos a ferramentas do dia a dia.

Suporte Externo: Oferece uma interface intuitiva para que parceiros e clientes encontrem ajuda, downloads e orientações sem a necessidade de suporte direto constante.

Futuramente, esta estrutura servirá de base para o meu site pessoal, evoluindo de uma ferramenta utilitária para um portfólio completo que une utilidade técnica e identidade visual.
